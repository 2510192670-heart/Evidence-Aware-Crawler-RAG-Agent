## Family and oracle isolation

Development contains one flat-envelope family with five behavior variants. The
other six families are on the frozen-evaluation side. Family-ID intersection is
empty; renamed equivalents with the same normalized structure cannot cross splits.
Signature tests ignore field names, IDs, URL paths, values and repeated same-shaped
members. A structural review is still needed before B dataset acceptance.

The frozen_evaluation label is an intended partition, not proof of an untouched
blind holdout. The A oracles have been inspected in authoring tests. No model-effect
claim should use this fact to imply unseen evaluation data.

Runtime projection accepts only public inputs and has no file I/O or scorer import.
Case/oracle metadata is rejected at the public boundary, including reserved metadata
inside a response. Existing cloud_summary redaction is reused. One synthetic canary
appears only in the allowlisted raw input JSON, not other evaluation JSON or the
planner-facing projection. Additional tests check accidental credential-shaped
material and absolute local paths.

Observed structural oracle-leakage violations: 0 in these checks. This is not a
live prompt/log/collector/diagnostic leakage rate: those paths were not run.

## Scoring and retrieval contract

Task success requires state, exact ordered output hash, schema, unique-key validity,
uniqueness, count, pages and completeness. Delivery success additionally requires
the existing export flags and independently matching collector results; flags alone
do not pass. Expected rejections are scored separately. Missing observations fail
closed rather than becoming a success.

Retrieval scoring compares returned IDs against external labels and uses MRR@2.
Missing failure_modes in E1/E2 output does not cause an artificial miss. Empty
relevance sets return N/A for hit/MRR; they are not counted as zero-quality queries.
No retrieval output was used to generate the labels; no quality improvement is
claimed. E1/E2/E3 metadata and identity mutations are tested negatively.
