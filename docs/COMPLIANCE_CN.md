# 中国法律合规使用指南

核对日期：2026-09-16。适用于本项目操作者的风险识别与操作审查，不是针对具体业务的律师意见、行政许可或合规认证。法律适用取决于行为、主体、数据类别、规模、用途与地点，不能仅凭“本地运行”“研究用途”或免责声明免除责任。商业部署、个人信息、重要数据或数据出境等场景应由中国执业律师及相关专业人员审查。

## 1. 使用前留下可核对的依据

对每个目标填写[采集审查模板](COLLECTION_REVIEW_TEMPLATE.md)：来源和用途、字段与数量、访问及处理依据、站点条款、robots、权利限制、模型接收方、保存期限、负责人和停止条件。未知项不得默认为许可。

网站公开可访问不等于可以任意采集、汇编、销售或再传播。robots 是本项目的技术约束之一，不是版权许可、个人信息处理依据或法律豁免。站点拒绝、出现认证/验证码、权利人异议或用途不明时先停止审查。

## 2. 个人信息与数据安全

《个人信息保护法》第十三条规定处理依据；第二十七条对已公开个人信息仍设合理范围、明确拒绝和重大影响等约束；第二十八条对敏感个人信息提出更严格要求。因此本版本的操作政策采用更保守范围：不以真实个人信息作为演示采集对象，不向模型提交个人资料。关键词未拦截不表示可以处理。[官方全文](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_f374e8245320413181742e6d1baf4366.html)

《数据安全法》第八条要求保护合法权益、履行数据安全义务；第三十二条要求合法正当地收集数据。应排除国家秘密、重要数据、商业秘密及其他受限内容，无法判定时停止。安全措施和分类需适合实际业务，不能由工具的 PUBLIC 标签代替。[官方全文](https://www.cac.gov.cn/2021-06/11/c_1624994566919140.htm)

《网络数据安全管理条例》自 2025-01-01 施行，涉及防护、委托/提供数据、事件处置等义务。操作者应确定访问控制、备份、保存和事件流程。本项目没有完整实现企业合规管理系统，内存密钥、脱敏和白名单只能提供部分技术控制。[官方全文](https://www.cac.gov.cn/2024-09/30/c_1729384452307680.htm)

## 3. 访问控制与公平竞争

使用者不得以欺诈、侵入、盗取凭证或规避技术管理措施获取数据，不得妨碍服务正常运行。2025 年修订的《反不正当竞争法》自 2025-10-15 施行，第十三条包含网络服务和合法数据权益保护规则。不能把“技术上能抓到”当作商业使用许可；批量替代原站服务、持续高负载或商业秘密风险需要专项审查。[官方全文](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_3737890d856a4e44a8ea07c50c90c116.html)

网络安全义务还需结合现行《网络安全法》评估；2025 年修改决定自 2026-01-01 施行，不应继续只引用旧版规则。软件不提供绕过登录、验证码、权限或反爬的支持。[官方修改公告](https://www.cac.gov.cn/2025-10/29/c_1763461514706581.htm)

## 4. 著作权与第三方权利

文字、图片及其他内容可能受著作权保护。少量研究使用、标注来源或非营利并不当然允许完整复制、公开汇编或重新分发；应逐项核对权利依据和法定例外。来源标注不能补足缺失的授权。下载 JSON/Excel 仅改变载体，不改变内容的权利状态。[《著作权法》官方全文](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)

MIT 仅授予本项目有权许可的软件权利，不授予网站、数据、商标、模型服务或他人隐私权益。开源许可中的担保限制不是免责通行证，不能排除强制性法律责任。

## 5. 模型调用与可能的数据出境

需求、结构摘要及案例提示会发往所选 API；服务器在本机不意味着全部数据留在境内。核对实际接收主体、处理地点、留存、训练使用、分包商及删除机制。使用供应商自定义 API 根地址还会改变接收方。

涉及个人信息或重要数据向境外提供时，需要结合《个人信息保护法》及现行数据出境规则核查义务、适用条件与例外；不以“量小”或“公开数据”作一概豁免判断。本版不提供自动法律判定或出境申报功能。[《促进和规范数据跨境流动规定》](https://www.cac.gov.cn/2024-03/22/c_1712776611775634.htm)

## 6. 对公众提供服务是另一项评估

当前本机内部使用和向境内公众提供生成式 AI 服务不能混为一谈。《生成式人工智能服务管理暂行办法》第二条明确其适用范围；若改为公众服务，需要结合实际功能评估生成式 AI、网络安全、备案、内容治理及其他适用义务，不能宣称“开源所以无需合规”。本版没有公众服务所需的账号、租户、安全运营与投诉处理能力。[官方全文](https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm)

## 7. 发现问题后的行动

停止任务与外发，隔离结果，撤销泄露凭证，核查模型、下载、备份的传播范围；最小化保留处置证据。依法及依约评估通知、报告、删除和权利请求。不要公开泄露内容，也不要以删除所有记录掩盖事件。联系路径见 [SECURITY.md](../SECURITY.md)。
