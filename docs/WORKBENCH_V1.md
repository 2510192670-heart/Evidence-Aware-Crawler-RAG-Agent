# 自然语言采集工作台 v1

本页描述当前开发工作树。已完成一次真实公网、模型和浏览器联合验证，具体证据见验收记录；尚未正式冻结或发布。历史 M5.4/M7 文档是对应阶段的记录。

## 启动

在项目根目录，使用已有 Python 虚拟环境和前端依赖：

```powershell
./scripts/start_workbench.ps1 -PolicyFile ./config/public-policy.example.json
```

打开 `http://127.0.0.1:8002/console/`。示例策略仅配置公开练习站 `books.toscrape.com`；其他网站需由本机操作者编辑部署策略文件并重新启动。未配置策略时保持本机靶场范围。程序仍会检查域名、DNS/IP、robots 和同源限制，配置白名单不等于目标必然可采集。

## 操作

1. 选择服务端默认模型，或展开“配置自己的模型”，输入 HTTPS API 根地址、模型 ID、密钥及供应商支持的输出选项。支持兼容 Chat Completions 的协议，不代表所有供应商都已验证。保存配置不调用模型。
2. 选择采集范围，填写页面 URL、description、字段名称。字段可进一步设置说明、类型、是否必须存在。
3. 选择自动识别、JSON 接口或网页列表/详情，设置最大页数和可选条数上限。
4. 创建任务，检查真实样本。确认请求绑定当前计划指纹，不重新调用模型。要调整字段，请取消并新建任务。
5. 查看结果表格、缺失统计、完成范围和 HTML 来源链接，下载 JSON、CSV 或 XLSX。

模型配置只在当前服务器进程内保存，重启后需重新填写；密钥不进入任务数据库、提示词产物或下载文件。原有环境变量方式仍受支持。

## 提取语义

- JSON：沿用观察到的 GET／JSON POST、页码字段和确定性执行器。可选字段缺失为 null；类型不匹配失败，不猜值。
- HTML：模型提出 CSS 选择器，程序在实际渲染页面上提取。只跟随页面中存在的同源列表分页或详情链接，不执行模型生成的代码。
- HTML 数字字段只支持明确的十进制文本，暂不自动解释货币单位或地区数字格式；不确定时选择“保持原始类型”。
- description 用于解释提取需求。不支持的筛选、聚合、摘要或额外交互应被明确拒绝，不能当作已经执行。当前版本不是通用浏览器 Agent。
- 最大 10 页；显式条数上限最多 1000；HTML 未填写条数时默认最多 100 条，每次提取最多 60 个列表/详情文档请求。初始观察和样本预览另有请求，全部计入任务总时限 180 秒。
- 预览最多等待 120 秒，且计入总时限。进程重启后待确认任务中断，不自动继续。
- `partial` 表示触及限制；`stop_condition_only` 表示遇到停止条件但没有网站总量证明；只有具有总量校验依据时才报告 `complete`。
- HTML 按完整提取行去重，并报告移除数量；不是跨站实体识别。

## 兼容性与边界

原有任务请求及十二种任务产物名称保持兼容；CSV/XLSX 从经过 hash 校验的 result.json 按需生成，不替换原文件。CSV 对公式样式文本加前导单引号；XLSX 使用文本单元格，防止把原始文字作为公式。

旧 GET/POST 独立 collector 模板未修改。使用可选字段、条数限制或 HTML 的任务当前不导出旧 collector；report 明确记录原因，数据文件导出仍可用。仅增加必填字段类型约束的 JSON 任务仍可走旧 collector 等价验证。

仍为本机单用户、单任务、单 worker。不支持登录态、验证码、跨源详情、任意 POST、cursor/offset 分页、分布式执行或京东淘宝专项适配。DataPolicy 与已有安全边界继续生效。
