# 单次目标采集审查记录模板

此表由操作者在本地填写，不提交包含敏感内容的实例到 Git。它不自动被程序读取，也不代表维护者批准。

| 项目 | 填写内容 |
| --- | --- |
| 日期 / 操作者 / 审查人 | |
| 目标域名及页面范围 | |
| 用途和必要性 | |
| 字段、条数、页数及频率 | |
| 访问和数据处理依据 / 授权范围 | |
| 网站条款、robots 核对日期及结论 | |
| 个人信息、重要数据、秘密排查 | |
| 著作权及再传播依据 | |
| 模型接收主体、实际处理地点、留存与训练政策 | |
| 保存期限、访问人员及清理方式 | |
| 停止条件与权利投诉处理人 | |
| 样本核对：来源、缺失、完整性 | |
| 结论：允许 / 拒绝 / 待澄清 | |

只有依据明确且属于程序支持范围时继续。审查不是自动授权通道；v1 不支持的认证等能力不能通过此表启用。
