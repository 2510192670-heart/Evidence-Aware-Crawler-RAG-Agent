# Task API Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline. Steps are independently verified; do not require cloud calls for automated tests.

**Goal:** 将已有浏览器/DeepSeek/采集 CLI 封装为可持久化的单任务 API，支持进度、取消、重启标记和产物下载。

**Architecture:** FastAPI 单进程管理一个 asyncio 工作任务，SQLAlchemy + SQLite 保存状态/事件/产物。Alembic 管理初始表结构。复用现有 pipeline，API 默认端口 8002，已有学习站继续使用 8000；Vue 后续再接入。

**Tech Stack:** Python 3.11、FastAPI、SQLAlchemy 2、Alembic、SQLite、asyncio、现有 httpx/Playwright/DeepSeek 网关。

**Spec:** [主设计](../../PROJECT_DESIGN_V0.1.md)，第 8/9 节。实现 M3 的任务/API 部分，不宣称完成脚本导出、RAG 或 UI。

## Global Constraints

- 一次只允许一个非终态任务，冲突返回 409。API 单 worker，无自动付费健康探测。
- 原生 CLI 保持可运行；可注入 task_id、输出目录和 async 进度回调。
- 密钥只留进程内存，不保存配置对象/凭证到 SQLite。
- 本机 loopback GET 目标范围保持不变；事件错误摘要不回显用户输入或网络响应。
- 取消是请求取消、等待资源释放、最终 cancelled；终态不得变回运行态。
- 进程启动将遗留非终态置为 interrupted，不恢复付费调用。正常停机取消运行任务。
- 文件通过 UUID 数据库映射下载，限制在 task 目录内，记录大小和 SHA256；不提供任意路径下载。
- 数据库操作通过 asyncio.to_thread；事务不能跨网络/模型等待。
