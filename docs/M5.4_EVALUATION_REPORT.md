## Safety Guarantees

- no new LLM call：截图只允许本地 GET；未创建新 Agent 任务或调用云模型。
- no execution change：C 不修改运行逻辑；Viewer 不提供执行入口。
- no repair boundary change：repair.py 仍控制确定性策略；诊断不参与修复。
- no artifact schema break：Trace 不新增任务 artifact，不修改原 artifact schema。
- advisory diagnosis only：诊断仅供查看，不重新规划。

初始规划与实际模型请求计数应区分，提前失败或既有连接重试可能改变 report.model_calls。真实成功样本的 2 次请求来自历史报告，不能改成 1。
